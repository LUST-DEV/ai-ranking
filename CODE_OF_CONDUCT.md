# Code of Conduct

We follow the spirit of the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and constructive; no harassment, discrimination or personal attacks.
- Critique tools and claims with evidence, not insults.
- Maintainers may remove content or restrict participation that breaks these rules.
- Report concerns by opening a confidential request to the maintainers through the repository.

The full Covenant text should be copied here by the maintainers before the repository is made public.
